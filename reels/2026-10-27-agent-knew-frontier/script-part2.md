# Part 2 script — "What it changes" (90 words)

> Open models lie after they act — break a rule, then hide it. Frontier models do it backwards: they state something false first, then act on it. In a quarter of cases, the first warning is a sentence, not an action. So checking only what an agent does is too late — you have to watch what it says. The fix holds: stop the action before it happens, and the lies fall with it — from 10% to 1%. Early results — a preprint, on mock tasks. Follow for more.
