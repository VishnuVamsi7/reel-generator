A finished job can hide broken steps. Prefix executability scores every prefix of a tool-call sequence, not just the final answer — where runs first break, and how many stay valid throughout.

On two hundred tasks, an agent following an unchecked plan finished ninety-four in a hundred, yet only forty-seven stayed valid. Checking the plan first lifted valid runs to ninety-four — same finish.

Honest limits: two-hundred-task samples, not a full leaderboard; checking did not help on every benchmark; an executable run proves nothing about correctness or safety.
