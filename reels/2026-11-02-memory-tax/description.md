## Description (110 words)

Your AI agent remembers everything — or does it? When it rewrites history into neat memory, it can quietly drop the detail you needed. That is the memory tax.

In one long-memory test, plain retrieval scored 81.4%, beating A-Mem (79.4%), LightMem (78.8%), MemOS (76.6%), and SimpleMem (73.6%). Memory is not uniformly worse — it helps sometimes — but the fix is to keep a recoverable path back to the raw source.

Paper: "Memory Tax: Dissecting the Net Value of Agent Memory," He et al., arXiv:2610.34073 (preprint, not peer-reviewed). Test: LongMemEval-s, Qwen3.6-27B.
