## Script — 83 words, ~36.9 seconds at 135 wpm (38.3s at 130 wpm, 35.6s at 140 wpm)

Your AI agent remembers everything. Or does it? When it rewrites your history
into neat memory, it can quietly drop the detail you needed. In one
long-memory test, plain retrieval scored eighty-one percent, beating every
fancy memory system in that test. That is the memory tax. Rewriting helps
sometimes, but it costs you evidence. The fix is simple: let memory organise,
but never delete the source. So keep a way back to the raw history. Follow
for a new AI paper every day.
